# 🚀 DevRoadmap Guide 2026

A modern, interactive web application designed to guide aspiring developers through the complexities of the 2026 tech landscape. This tool provides personalized learning paths for **Python, JavaScript, Java, C#, C++, and Go** based on seniority levels and specific tracks (Frontend, Backend, Full Stack).

![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Key Features

-   **Universal Foundation:** A shared baseline for all developers covering DSA, Git, and HTTP fundamentals.
-   **Smart Logic:** Automatically suggests Full-Stack pairings for languages that are backend-only (e.g., Go, C#, Java).
-   **Persistent Progress:** Unique progress tracking per path (Language + Level + Track) saved to LocalStorage.
-   **2026 Tech Stack:** Includes modern tools like HTMX, FastAPI, Next.js SSR, and Cloud-Native Go.
-   **Interactive UI:** Tabbed interface with real-time progress bars and printable checklists.

## 🛠️ Built With

* **HTML5 / CSS3**
* **Tailwind CSS** (via CDN for rapid prototyping)
* **Vanilla JavaScript** (ES6+ Architecture)
* **Lucide Icons** (Scalable vector icons)

## 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/devroadmap-guide.git](https://github.com/your-username/devroadmap-guide.git)
    ```
2.  **Navigate to the folder:**
    ```bash
    cd devroadmap-guide
    ```
3.  **Run the App:**
    Simply open `index.html` in your favorite browser. No build steps or servers required!

## 📂 Project Structure

- `index.html` - The landing page.
- `SignInPage.html` / `SignUpPage.html` - Authentication interface.
- `DashboardPage.html` - Path selection engine.
- `RoadmapPage.html` - The dynamic roadmap renderer.
- `app.js` - The core engine containing the Master Database and Progress Logic.

## 📝 Roadmap Data
The application currently supports:
- **Python:** Backend (FastAPI/Django) & Full Stack (HTMX/React).
- **JavaScript:** Frontend (React/Next.js), Backend (Node), & Full Stack.
- **Java/Go/C#/C++:** Specialized Backend tracks with Full Stack suggestions.
